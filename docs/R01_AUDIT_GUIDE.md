# R01 정상 점수 분포 원인 검토

E15B/C에서 영상별 동일 가중 보정으로 R01의 historical 정상 오경보가 개선되지 않았다. 이 packet은 영상·공정 상태·라벨 해석에 대한 **독립 검토 준비물**이며 원인 판정 결과가 아니다. 인간 검토 완료는 0개다.

- 로컬 뷰어: `runs/r01_audit/index.html`.
- 검토 대상: 문맥 구간 43개. 균등 표본 23개와 점수 기반 탐색 20개를 구분한다.
- 균등 표본 층: fold 0 reference 4개, threshold 4개, normal-evaluation 5개, historical 첫 양성 이전/양성 없음 5개, 첫 양성 이후 정상 5개. 각 층에서 원본을 중복 없이 추출한다. 같은 원본이 다른 층 또는 탐색 묶음에 다시 나올 수 있으므로 43개를 독립 영상 수로 세지 않는다.
- 점수 기반 탐색: 같은 5개 층 각각에서 Full 점수 중앙값이 낮은 원본 2개와 높은 원본 2개를 선정한다. 원본 내 10%/90% 분위수에 가까운 프레임을 중심으로 문맥을 제공한다. 이 묶음의 구성비는 모집단 발생률이 아니다.
- 뷰어는 Q001 등의 무작위 순서 ID와 상대 프레임만 표시한다. 점수·예측·라벨·층·선정 이유는 표시하지 않는다. 전체 출처와 선정 manifest는 분석용이며 검토자에게 먼저 보여주지 않는다.
- 원본 프레임과 접촉시트는 로컬에만 보관한다.

검토자 A/B는 각각 `runs/r01_audit/annotator_A.json`, `annotator_B.json`에 조명/시점/배경, 공정 상태, 잔류 물체·결함, 판독 불확실성을 독립 기록한다. 상대방 판단과 모델 점수 없이 1차 기록한 뒤 불일치와 합의 과정을 별도로 보존한다. 생성 스크립트는 기존 A/B 기록을 덮어쓰지 않는다.

라벨 정합성 검토가 필요하면 독립 시각 판독을 먼저 고정한 뒤 원 라벨을 공개해 2차 adjudication을 수행한다. 원 라벨을 유지하고 수정본 평가는 별도 버전으로 보고한다. Historical 정상 프레임을 calibration에 넣지 않는다. AI 판독을 인간 검토 완료로 기록하지 않는다.

E7B의 실제 cycle·단계 주석은 별도 [기존 40개 주석 안내](ANNOTATION_GUIDE.md)를 따른다. 이 R01 원인 검토 packet을 위치 정확도 GT로 대체하지 않는다.
