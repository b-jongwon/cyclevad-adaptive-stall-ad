# 로컬 개선 1: 점수는 유지하고 경보를 개선

## 왜 정상인데 경보가 많았나

기존 임계값은 각 장면의 정상 holdout에서 하나를 정한다. 새 테스트 영상에서 조명·입력 상태·초기 추적 상태 등의 차이로 정상 점수 전체가 높아지면 정상 프레임도 기준을 넘을 수 있다. 특히 R01에서 이 문제가 크게 나타났다.

“정상 영상을 사용하지 않고 강도로 임계값을 정한다”는 표현은 정확하지 않다. 정상 기준 없이 임계값의 의미를 안정적으로 정하기 어렵다. 실제 구현은 **정상 자료로 기본 기준을 만들고, 라벨 없는 현재 영상의 시작부 강도로 기준을 일부 보정**한다.

## 초기 R01–R04 탐색의 파이프라인

```text
정상 fit → 기존 CycleVAD
정상 reference → 시작부 낮은 점수 기준 + 위치별 motion 분포
정상 threshold → 기본 임계값 + 정지 점수 임계값

테스트 특징 → 기존 score 유지
  ├ 영상 시작부 낮은 20% → 기준 차이 → 임계값 일부 상승
  └ lag1/4 motion → 위치별 lower-tail → EMA → 8관측 중 3회 정지 경보
→ 두 경보 OR → frame/event 평가
```

시작부 24개 관측 중 낮은 20%의 중앙값을 사용해 일부 높은 이상 점수의 영향을 줄인다. 정상 reference의 같은 기준과의 차이를 구해 기존 임계값에 0.3배만 더한다. 무조건 전체 차이를 빼거나 임계값을 크게 올리면 이상까지 숨길 수 있다.

초기 구현은 영상 시작 24개 관측을 읽어 전체 영상의 경보 기준을 계산하는 탐색 방식이다. 이 시작부 경보를 완전한 온라인 처리라고 부르면 안 된다. 다음 전체 16개 규칙에서는 초기 23관측의 경보를 소급해서 바꾸지 않도록 수정했다.

`fixed_cyclevad`는 기존 점수/기준이다. `intensity_threshold`는 경보 임계값만 바꾸므로 AUROC/AP는 같다. `intensity_threshold_with_stall`은 별도 정지 경보를 OR한다. 이 단계의 AUROC/AP는 여전히 기존 연속 score로 평가하므로 정지 경보의 효과가 AUROC에 반영되지 않는다.

`phase_combined`, `phase_branch`는 기존 점수를 위치 bin별 percentile/tail로 다시 바꾼 것이다. 멘토의 phase별 별도 covariance subspace 모델을 새로 학습한 것과 다르다. `warmup_phase`, `adaptive_ema`, `adaptive_with_stall`처럼 점수 자체를 강하게 보정한 설정은 낮은 FPR과 함께 recall을 크게 잃었다. 이런 설정을 최종 개선 성공 사례로 제시하지 않는다.

초기 합성 freeze는 정상 validation 특징 일부를 반복한 실험이다. 4개 장면·45개 편집 조건씩 총 180건이며, 실물 장비 고장 180건을 촬영한 것이 아니다. 합성 정지 93.33% 탐지와 실제 이상 recall 47.54%는 다른 지표다.

## 전체 16개 장면: 하나의 공통 경보 규칙

`universal_alarm.py`는 전체에 같은 하이퍼파라미터를 적용한다. 영상별 분포를 정상 자료로 추정하는 절차도 같고, R01에는 특별 예외 규칙을 넣지 않는다.

기존 score s는 그대로 두고, reference에서 정상 영상의 시작부 낮은 20% 점수 중앙값 B를 추정한다. 테스트 시작부 24관측의 같은 값 b에서 `offset=max(0, b−B)`를 계산한다. 초기 23관측은 기존 임계값 T0를 유지하고, 24번째부터 `T=T0+0.3×offset`을 사용한다. 그 뒤 offset을 고정한다.

점수가 낮은 새 영상에 기준을 낮추지 않는 단방향 보정이다. 시작부 전체가 이상이라면 낮은 20%도 이상일 수 있다. 따라서 오염을 줄이는 장치이지 초기 정상 상태를 보장하는 장치는 아니다.

CycleVAD 경보는 선택된 persistence 1, 정지 경보는 연속 3관측을 사용한다. 초기 4장면의 **8관측 중 3회**와 후속 **연속 3회**는 다른 정책이다. 동일한 정지 모듈의 개선 과정이지만 결과를 같은 조건으로 합치면 안 된다.

## 정지 분기의 의미

global 특징은 정규화되어 있으므로 현재/과거 dot product로 cosine similarity를 구한다. motion=1−similarity가 작으면 화면 특징이 거의 변하지 않았다는 의미다. lag 1과 4 두 시간 폭을 본다.

정상 reference의 θ를 16개 bin으로 나눠 motion 분포를 저장한다. bin에 64개 미만의 정상 관측이 있으면 전체 정상 분포로 fallback한다. 정상 대기 위치에서는 작은 motion이 흔하므로 lower-tail 점수가 작을 수 있고, 움직여야 하는 위치에서 유난히 motion이 작으면 점수가 커진다.

lower-tail은 “정상 자료 중 이만큼 적게 움직이는 경우가 얼마나 드문가”를 측정한다. lag1/lag4 두 점수의 **min**을 취해 둘 다 움직임 부족을 보일 때 강한 증거로 읽고 EMA alpha 0.5로 평활화한다. 정상 threshold에서 q99.5 기준을 만든다.

주의: 현재 `_motion` 함수는 앞의 lag개 관측에 첫 계산 가능한 이후 motion 값을 복사한다. lag 4에서는 첫 4관측이 5번째 특징에 의존한다. 따라서 임계값 보정 규칙은 causal하게 수정했지만 **전체 정지 분기까지 완전 causal하다고 검증된 것은 아니다.** 이 문제를 고친 다음 새 수치로 평가해야 한다.

## 공통 규칙은 어떻게 골랐나

gain 0/0.1/0.2/0.3, persistence 1/2/3, stall 사용/미사용의 24개 조합을 정상 validation과 그 특징의 합성 freeze/reversal로 비교했다. 실제 테스트 이상 라벨을 이 규칙 선택에 사용하지 않았다.

조건은 기존 대비 정상 validation macro FPR 증가 0.5%p 이하, 장면별 증가 2%p 이하, 합성 frame recall 하락 1%p 이하이다. 조건을 통과한 후보에서 `합성 frame recall + 합성 event coverage − 5×정상 FPR`이 큰 설정을 선택했다. gain 0.3, persistence 1, stall true가 남았다.

정상 validation FPR은 1.54→1.50%, 합성 frame recall은 5.07→39.75%, 합성 event coverage는 24.09→71.35%였다. 실제 테스트에서 동일한 향상을 보장하지 않는다.

이 규칙의 16개 장면 테스트 평균 AUROC/AP는 원본과 정확히 같다. FPR 10.12→9.40%, Recall 17.24→30.83%, F1 18.58→35.14%, event coverage 43.24→80.27%로 변했다. 점수 보존과 경보 개선을 분리해 입증한 실험이다.

`universal_all16/execution.json`의 164.6초는 기존 특징 캐시를 재사용한 경보 실험 시간이다. DINOv2 다운로드·전체 특징 추출·미완료 기본 모델 학습을 모두 포함한 총 학습 시간이 아니다.
