# 로컬 개선 2: 무엇을 직접 학습했나

## 학습과 기준 추정을 구분

CycleVAD의 PCA·Fourier 평균·normal memory·템플릿은 정상 데이터에서 학습하는 모델이다. 다만 backpropagation을 수십 epoch 반복하는 신경망 학습은 아니다. 사전학습 DINOv2를 동결했다고 프로젝트 전체가 아무것도 학습하지 않은 것은 아니다.

추가 실험에서는 작은 **denoising autoencoder(AE)**와 **GRU predictor**의 가중치를 실제로 gradient로 업데이트했다. 전체 16개 장면 각각 AE와 GRU를 하나씩 학습했으므로 32개의 신경망 head다. DINOv2 encoder 자체는 갱신하지 않았다. 이 단계에도 GPT/VLM이나 유료 API 호출은 없다.

## 공통 특징 전처리

global 정상 fit 특징에서 최대 8,192개를 영상별 균형 샘플링하고 PCA 최대 64차원으로 줄인다. 각 축의 정상 표준편차로 나눠 스케일을 맞추며 최소 scale 0.01을 사용한다. 여기의 PCA는 특징 추출기의 patch random projection과 다른, 정상 자료 기반 학습이다.

fit은 head 학습, validation은 checkpoint 선택, reference는 출력 점수 scale, threshold는 경보 기준에 사용한다. 테스트 라벨은 예측과 경보 생성 뒤에 평가할 때 읽는다.

## 정상 memory 세 가지

**Global NN:** 정상 전체 특징 bank 최대 1,024개를 저장한다. 현재 전체 특징과 정상 bank의 squared Euclidean 최근접 거리를 읽는다. 전체 모습이 학습 정상과 비슷한지 본다.

**Patch NN:** 각 화면 위치의 정상 bank 최대 512개를 저장한다. 같은 위치끼리 최근접 거리 계산 후 전체 평균 또는 큰 4개 위치 평균으로 읽는다. 전체 평균은 잡음에 덜 민감하지만 작은 불량이 묻힐 수 있다. top-4는 국소 불량에 민감하지만 국소 조명·배경 변화에 취약하다.

**Motion NN:** 4관측 전 patch 특징을 뺀 변화를 정상 bank 최대 256개와 비교한다. 여기서는 “정상과 다른 변화 형태”가 높은 점수다. 반면 최종 stall 모듈은 “정상보다 변화가 너무 작다”를 별도로 읽는다. 두 방법 모두 temporal이라는 이유로 같은 점수라고 생각하면 안 된다.

## AE: 정상 특징을 다시 만들기

구조는 PCA 특징 약 64→64→16→64→64이고 중간에 GELU를 사용한다. 입력에 표준편차 0.03의 작은 Gaussian noise를 넣고 원래 정상 특징을 복원하도록 MSE를 줄인다. 손상된 입력에서 정상 구조를 복원하는 denoising 학습이다.

추론 점수는 입력 특징과 복원 특징의 MSE다. 정상에서 복원 오차가 작고 이상에서 클 것이라는 가설이다. 그러나 AE가 이상도 잘 복원하면 구분력이 약해진다. 정상 validation loss가 내려갔다고 이상 탐지 AUROC도 반드시 올라가는 것은 아니다.

이 AE는 원본 영상 픽셀을 깨끗하게 고치거나 제품 불량을 복구하는 모델이 아니다. 숫자 특징을 재구성하는 이상 탐지 head다.

## GRU: 과거 특징으로 현재 특징 예측

과거 8관측의 PCA 특징을 GRU hidden 64에 넣고 Linear 층으로 현재 약 64차원 특징을 예측한다. 현재 특징을 예측 입력에 넣지 않는다. 예측 오차 MSE가 이상 점수다. 시작부의 부족한 과거는 첫 관측을 반복해서 채운다.

stride 2 기준 과거 8관측은 약 16원본 프레임 범위다. 현재 구현은 매우 짧은 시간 문맥이다. 긴 공정 순서 전체를 이해한다는 뜻은 아니다. 정상 대기와 이상 정지가 모두 예측하기 쉬우면 정지에 낮은 오차를 줄 수도 있다.

AdamW lr 0.001, weight decay 0.0001, 학습 batch 256, 평가 batch 512, gradient clipping 1.0을 사용했다. 최대 30epoch, 정상 validation loss가 약 0.1% 이상 개선되지 않는 상태가 4번 지속되면 조기 종료한다. 저장된 학습 이력상 모든 head가 30epoch까지 실행됐다.

checkpoint는 “마지막 epoch”가 아니라 구현에서 validation 개선 기준을 통과한 가장 좋은 가중치를 복원한다. 표의 최저 validation epoch는 단순 argmin으로 계산한 기록이며, 0.1% improvement gate 때문에 저장 checkpoint epoch와 엄밀히 동일하다고 단정하지 않는다.

## 16개 특징 실험 설정

모든 raw 점수는 정상 reference의 TailCalibrator와 log1p 압축을 거쳐 단위를 맞춘다. log1p는 매우 큰 한 분기가 평균 결합을 독점하는 것을 줄이기 위한 것이다.

| 설정 | 들어가는 경로 | 비교하려는 가설 |
| --- | --- | --- |
| baseline | 기존 CycleVAD | 같은 기준선 |
| global_nn | 전체 정상 bank | 전체 외형 최근접 비교의 충분성 |
| patch_mean / patch_top | 위치별 정상 bank | 평균과 국소 민감도의 절충 |
| motion | patch 변화 bank | 정상 움직임 패턴과 다른가 |
| ae / gru | 재구성 / 예측 오차 | 학습 head가 더 좋은 표현을 만드는가 |
| prototype | 0.5 global + 0.5 patch_mean | 두 정상 memory 결합 |
| spatial_temporal | 0.7 prototype + 0.3 motion | 외형+움직임 novelty |
| learned | 0.5 AE + 0.5 GRU | 재구성과 예측의 보완성 |
| full_features | 0.5 prototype + 0.2 motion + 0.15 AE + 0.15 GRU | 모든 head의 단순 결합 |
| cycle_prototype | 0.5 보정 cycle + 0.5 prototype | 기존 공정 score+외형 memory |
| cycle_full | 0.25 보정 cycle + 0.75 full_features | 기존 score+모든 head |
| prototype_ema / full_ema / cycle_full_ema | 해당 score EMA 0.4 | 시간 평활화의 효과 |

새 head score들의 경보에는 기존 공통 정지 OR 정책도 유지된다. 따라서 특징 arm의 F1은 “그 head만 단독으로 만든 경보”가 아니라 **그 score+공통 경보 체계**의 수치다. AUROC/AP는 해당 score의 연속 순위로 계산한다.

## 결과를 어떻게 해석하나

global NN AUROC 64.43%, AE 62.99%, GRU 54.37%, full_features 56.72%로 기존 CycleVAD 67.28%보다 낮았다. motion novelty는 36.25%였다. 움직임이 클수록 이상이라는 일반 novelty 접근이 정지 중심 문제에 맞지 않을 수 있다는 관찰이다. 다만 1개 seed·해당 구현 조건이므로 GRU나 prototype 일반 방법론 자체가 나쁘다고 결론 내리면 안 된다.

모든 head가 30epoch를 돌아 정상 loss가 낮아졌어도 탐지 구분력은 좋아지지 않았다. 현재 근거로 AE+GRU를 최종 파이프라인에 반드시 넣을 이유가 없다. 최종 균형 후보는 이 neural head들을 제외하고 기본 CycleVAD와 lower-motion 정지 점수만 사용한다.

상세 결과 16개 설정과 장면별 수치는 7페이지와 `results/feature_study_all16`에서 확인한다. GPU 학습 checkpoint는 로컬에 보존했지만 새 공개 Git 저장소에는 원시 영상·특징 cache·대형 모델 파일을 포함하지 않았다.
