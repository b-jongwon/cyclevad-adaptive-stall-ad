## 계산하지 않은 지표를 만들지 않는다

저장된 per-video 결과에는 일부 경보 시작 횟수와 탐지 지연이 있지만, 전체 duration/FPS metadata가 확인된 시간당 false alarms나 모든 미탐을 포함한 time-to-detect 요약은 이 최종 표에 없다. micro AUROC·pixel AUROC·PRO·object localization 정확도·실제 고장 유형별 recall·새 공정 적응 시간·RTX4060 end-to-end FPS도 현재 최종 후보에서 검증한 지표가 아니다.

팀원 표의 F1은 TP/FP/FN을 복원해 계산한 파생값이다. 팀원 원본이 제공하지 않는 precision/event metric을 임의로 채우지 않는다. 공개 JSON에는 표에 반올림하지 않은 원래 수치를 보존한다.

## 결과 우선순위

기존 README의 요약과 새로 생성한 표가 충돌하면 **해당 실험의 원시 JSON → 이 자동 생성 비교표 → 과거 문장 요약** 순서로 확인한다. 서로 다른 실험 결과를 동일 baseline처럼 섞지 않는다. 예를 들어 초기 R01–R04 평균 78.28%와 16장면 평균 67.28%는 둘 다 초기 CycleVAD 결과지만 평균 범위가 다르다.
