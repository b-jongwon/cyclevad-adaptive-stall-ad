## 1. 현재 성립하는 논문 주장

핵심 문장은 다음과 같다.

> 반복 공정의 정상 외형을 인과적으로 추정한 잠재 진행 좌표에 조건화하고, 위치별 평균을 제거한 잔차를 공유 subspace에서 평가한다. 진행 불일치 신호는 별도로 측정하여 외형 이상과 다른 탐지 특성 및 결합의 한계를 검증한다.

C를 주 모델, C+P를 확장 모델, A와 Full을 대조군으로 배치한다. P가 모든 공정에서 실제 탐지를 개선한다는 주장은 아직 하지 않는다. 실험상 유효성과 문헌상 최초성은 별개이며, 외부 baseline 및 선행연구 비교는 여전히 필요하다.

| 주장 | 현재 근거 | 추가로 필요한 증거 |
| --- | --- | --- |
| 위치 조건부 평균 + 공유 잔차 subspace가 유용하다 | E8B 위치 대조, E12 head 비교, E11B C AP 72.42% | 외부 구현 baseline, rank/메모리 민감도, 독립 자료 |

| P는 시간 교란에 반응한다 | 합성 편집, E11B P 단독 평가 | 단순 시간 모델·강한 causal 모델·편집 경계 대조 |

논문 초안과 핵심 도표 작성은 시작할 수 있다. 현재 결과만으로 현장 운영 성능이나 광범위한 진행 이상 탐지의 우수성이 입증되었다고 표현하지 않는다.

## 2. 제공 보고서와 일치하는 점과 보완할 점

[E11B/E15A 결과](PAPER_DIAGNOSTICS_RESULTS.md)의 주요 수치와 제공 보고서는 일치한다. CP−C AP는 +1.01 pp이나 CI는 [−1.81,+4.68]이다. R02 제외 AP −2.21 pp의 CI는 [−4.73,+0.04]로 0을 포함하며, AUROC −2.86 pp의 CI [−5.16,−0.62]는 음수다. C 33/66 대비 CP 29/66은 추가 3, 손실 7이다. A의 필수성은 약하지만 CP의 Full 대비 통계적 우월성도 확정하지 않는다.

보완해야 할 해석은 네 가지다.

1. **경보 보존과 오경보 예산은 상충할 수 있다.** 동일 정상 창 집합에서 원 C 경보를 그대로 보존하는 OR의 FAR은 `FAR(C) + FAR(P and not C)`다. P의 정상 추가 경보가 있으면 전체 FAR은 증가한다. 분기별 OR 자체가 이 문제를 해결하지 않는다.
2. **R01 원인은 아직 미확정이다.** 정상 OOF 5.46%는 5개 fold 모델, historical 45.87%는 fold 0 모델이다. 직접 분포 비교는 같은 fold 0의 정상 holdout과 historical을 사용하고, 전체 OOF는 보조로 둔다. 사후 정상 100%는 추적 상태, 실제 잔류 결함, 정상 라벨의 의미 등 여러 설명이 가능하다.
3. **E9S P4는 순수 P가 아니다.** 코드상 P4는 A와 alignment/innovation/progress의 max이며, 보고서의 78.66%는 합성 window AUROC다. 순수 진행 분기의 성능은 E11B P 또는 새 공정한 P 단독 대조로 표현한다.
4. **현재 q99는 정밀한 1% 경보 통제를 입증하지 않는다.** seed 42의 threshold 표본은 장면·fold당 원본 3–4개, 겹치는 창 21–33개다. 전체 60개 단위 중 37개에서 C/P/CP 세 분기 모두 q95와 q99.5 임계값이 동일하다. 높은 분위수에서 방법이 같아지는 현상을 반드시 표시한다.

마지막 수치는 기존 `results/E11B/seed*/R*/fold*/run.json`의 `threshold_window_counts`와 `window_thresholds`를 읽어 집계했다. 새 모델 평가 결과가 아니다.

## 3. 바로 다음 실행: E15B0 → E15B/C

### E15B0: 경보 손실과 보정 해상도 진단

고정 E11 checkpoint와 기존 C/P 점수를 사용한다. 학습이나 새로운 가중치 선택 없이 다음을 산출한다.

- 기존 C 단독, 기존 joint-max CP, C/P 각자의 원래 q99 임계값을 유지한 OR의 이벤트별 탐지 표.
- C가 잃은 7개 이벤트에 대해 C/P peak, 각 임계값, deadline 내 첫 초과 시점, 손실 이유. label이나 peak로 새 임계값을 선택하지 않는다.
- 정상 창에서 `C only / P only / both / neither` 비율. 원 임계값 OR가 복구하는 이벤트와 추가 정상 경보의 비용을 짝지어 보고한다.
- threshold 원본 수, 창 수, 중첩 정도, 양의 가중치와 동률을 고려한 ECDF jump, 서로 다른 임계값 수. q90/q95/q97.5/q99/q99.5와 분기별 예산 임계값을 모두 공개한다.
- 정상 threshold 원본을 하나씩 제외하고 임계값만 재산출하는 안정성 분석. 제외 후 2개 미만이면 unavailable이다. 모델 선택에는 사용하지 않는다.

정상 창을 촘촘히 재추출하여 독립 보정 자료가 늘었다고 주장하지 않는다. 동일 원본의 편집/증강도 독립 영상으로 세지 않는다. 높은 분위수가 같은 관측 최댓값에 걸리면 해당 비교는 **운영점 구분 불가**로 표시한다.

### E15B: reference 가중 방식만 분리

추적기, μ, PCA, raw C/P를 고정한다. 새 backbone 학습은 없다.

| ID | reference 변환 | 목적 |
| --- | --- | --- |
| G0 | 기존 pooled frame empirical log-tail | 정확한 재현 기준 |
| G1 | 영상별 총 가중치를 같게 둔 component empirical log-tail | 긴 reference 영상이 지배하는 효과 분리 |

G1에서 각 reference 영상의 stride-2 표본 수가 n_i이면 표본 가중치는 `1/(m*n_i)`다. 가중 midrank CDF를 F_w, 전체 reference 표본 수를 N이라 할 때 tail은 `(N*(1-F_w)+1)/(N+1)`로 정의한다. log 변환, reference 최대값 초과의 선형 외삽, 외삽 scale은 G0와 동일하게 고정한다. 따라서 가중 방식과 tail 포화/외삽 변경을 혼합하지 않는다. N은 기존 smoothing을 보존하는 값이며 독립 표본 수라는 뜻이 아니다. 비유한 값이나 빈 reference는 실패 처리한다.

분기 점수는 기존대로 `C=max(C_outside,C_inside)`, `P=max(alignment,innovation,progress)`다. 각 G에서 C 단독도 반드시 다시 평가하여 보정 개선을 P의 기여로 잘못 돌리지 않는다.

기존 계획의 G2 phase별 보정은 이번 주 비교에서 제외한다. 현재 reference 원본이 적고 실제 θ 의미도 미검증이므로, G1과 E7B 결과 이후 별도 설계로 다룬다. Confidence gate, 장면별 P on/off, 이상 라벨로 학습한 가중치는 이번에 추가하지 않는다.

### E15C: 동일 명목 예산에서 제한된 결합 비교

각 G에서 아래 네 정책을 평가한다. **2개 보정 × 4개 정책 = 8개 주 조건**, 원 임계값 OR 진단 2개를 더한다. P/Full의 기존 E11B 결과는 맥락 비교로 유지하되 새 조건과 섞어 직접 개선량을 계산하지 않는다.

| ID | 경보 규칙 | 명목 정상 창 예산 |
| --- | --- | --- |
| F_C | C 단독 | α_C=α |
| F_MAX | max(C,P)의 결합 임계값 | α_CP=α |
| F_OR75 | 분기 임계값 OR | α_C=0.75α, α_P=0.25α |
| F_OR50 | 분기 임계값 OR | α_C=α_P=0.5α |
| D_OR | C/P 단독 임계값을 유지한 OR | 각각 α; 전체 α 조건의 주 비교에서 제외 |

α=1%는 기존 결과와 연결하는 주 운영점이다. α=5%,10%도 **해상도와 비용-효과 민감도**로 모두 공개하며 현장 허용 목표로 제시하지 않는다. 75:25는 C 중심 설계 가설에 따른 사전 선택, 50:50은 대칭 대조다. 테스트 결과로 유리한 비율을 고르지 않는다. 1%에서 정책들이 같은 임계값이면 차이가 없는 이유를 표시하고 더 많은 독립 정상 보정 자료가 필요한 것으로 결론낸다.

분기 임계값은 현재 방식과 동일하게 정상 THR의 영상 동일 가중 D-window 최대값 분위수로 구한다. OR도 원 코드와 동일한 엄격한 `>`를 사용한다. 예산 합은 설계값일 뿐, 현재 유한 표본·의존성·분포 차이 아래 실제 FAR 보장이 아니다.

F_MAX의 연속 score AP/AUROC는 보조로 보고한다. F_OR는 이산 경보 정책으로 평가하며, 임계값으로 나눈 임의 점수를 새로운 AP 개선 근거로 만들지 않는다. 정책 비교의 중심은 event detection과 정상 경보 비용이다.

### 자료·실행·평가 규칙

- 기존 FIT/VAL/REF/THR/normal-evaluation 분리와 seed 42/43/44, 4장면×5-fold를 유지한다. Historical은 기존 fold 0만 평가한다. C/P 모델은 E11 checkpoint를 고정한다.
- FIT는 모델, VAL은 이미 고정된 모델 선택, REF는 component 변환, THR는 임계값에만 쓴다. Historical 라벨과 합성 이상은 평가에만 사용한다. 현재 historical은 반복적으로 확인한 개발 자료로 명시한다.
- 순서: seed 42 R01 fold 0에서 재현/동률/누수 검사를 먼저 수행한 뒤 60개 단위 전체를 실행한다. Smoke 결과가 나쁘다는 이유로 특정 장면이나 정책을 삭제하지 않는다.
- 고정 CUDA 특징을 재사용한다. 새 raw 편집 점수가 필요하면 로컬 RTX PRO 6000 환경의 기존 특징으로 causal tracker를 재생한다. 기존 `edited_windows.npz`의 결합 점수만으로 G1을 역산하지 않는다. 편집별 raw component와 θ, prefix 동일성, checkpoint/config hash를 저장한다.
- 정상 창 정의, startup 32프레임, T/D/W, 편집 ID와 ZOH는 기존 프로토콜을 유지한다. T는 FIT 녹화 길이 척도이며 실제 cycle 길이 정답이라고 부르지 않는다.
- 주지표: deadline 내 이벤트 탐지, C 대비 유지/추가/손실, 정상 grid/matched window FAR. 프레임 FPR·recall, 경보 지속 비율, 탐지 지연도 병기한다. 이들 단위를 혼합하지 않는다.
- 실제 경보/시간은 FPS와 연속 녹화 관계가 검증된 자료에서만 추가한다. 검증되지 않은 clip을 이어 붙여 시간당 경보율을 만들지 않는다.
- 이벤트 비교 기준을 두 개 둔다: 같은 G의 F_C 대비 P의 순효과, 원 G0/F_C 대비 전체 변경 효과. 서로 다른 α에서도 같은 α의 C와 비교한다.
- seed 42의 동일 원본 영상 paired bootstrap 2,000회로 recall 차이, 유지/추가/손실, FAR 차이의 CI를 계산한다. 합성 편집은 source 단위로 묶고, source/session 연결이 확인되면 그 상위 그룹을 사용한다. 프레임과 편집을 독립 표본으로 세지 않는다.
- 3개 seed는 모델 안정성으로 별도 보고한다. 동일 영상을 seed 수만큼 독립 표본으로 늘리지 않는다. 전체/장면별/4개 leave-one-scene-out을 모두 공개한다.

### 판정과 중단 기준

결합 성공의 평가 방향은 탐지 추가, 손실 감소, 정상 비용의 균형이다. 같은 명목 α만으로 같은 실제 FAR이라고 쓰지 않는다. THR에서 고정한 임계값을 evaluation 정상 라벨로 이동시켜 FAR을 사후 일치시키지 않는다.

- 동일 G·α에서 실제 정상 FAR이 비슷하거나 낮으면서 event recall이 높으면 유망한 결합 후보다. 둘 중 하나만 좋아지면 trade-off로 보고한다. 원본 단위 CI가 넓으면 불확실하다.
- 후보를 사후 선택해 독립 확인으로 넘기면 개발 선택 사실을 기록한다. 이번 historical/합성 결과를 정상-only 최적화나 독립 검증이라고 부르지 않는다.
- 보정만으로 C가 좋아지고 P의 순효과가 없으면 C 중심 논문을 유지한다. P의 새 모듈을 계속 추가하여 현재 평가에 맞추지 않는다.
- 높은 분위수 해상도가 부족하면 정밀한 1% 결합 최적화는 중단하고 정상 보정 자료 확보로 전환한다. 양성 이득이 없다는 결과와 측정 해상도가 부족하다는 결과를 구별한다.
- 기존 로드맵의 FAR≤2%/장면≤5% 및 합성 recall screening은 이번 주 방법의 자동 선택 기준으로 사용하지 않는다. 이번 조건을 전부 공개하고, 결과를 보고 다음 독립 확인 방법을 별도로 고정한다.

산출물: 8개 조건 운영표, 진단 OR 비용표, 7개 손실 이벤트 추적 그림, threshold 해상도/민감도 그림, 실제·합성 이벤트 추가/손실 도표, source CI. 완료된 단계만 README와 GitHub에 결과·설정·실패 조건을 함께 업데이트한다.

## 4. 병행할 R01 원인 점검과 E7B 주석

R01 점검은 결합 개선과 분리한다. 같은 fold 0의 REF/THR/normal-evaluation/historical 점수 분포를 비교하고, historical의 첫 양성 이전/이후를 구분한다. A가 추적 상태 없이도 높은 이유를 함께 본다.

원본 영상 검토는 두 표본 묶음을 만든다. (a) 정상 출처별·historical 사전/사후 구간별 균등 무작위 표본은 대표성 점검에 사용하고, (b) 높은/낮은 점수 사례는 원인 탐색에 사용한다. 가능한 각 층에서 고정 seed로 5개 원본의 문맥 포함 구간을 뽑고 부족하면 전부 사용한다. 두 묶음의 비율을 합쳐 모집단 발생률로 보고하지 않는다.

검토 화면에서는 방법 이름·점수·경보를 숨기고 조명/시점/배경, 공정 단계, 잔류 물체·결함, 라벨 경계의 의미를 기록한다. 검토자 2인의 합의 전 판단을 보존한다. AI 초안은 독립 인간 주석을 대체하지 않는다. 원 라벨은 유지하며 수정이 필요하면 별도 adjudicated 버전과 원 라벨 평가를 함께 공개한다. Historical 정상 마스크를 새 보정 학습에 넣지 않는다.

E7B는 [기존 주석 설계](PAPER_STAGE2_DESIGN.md)를 따른다. 장면별 FIT 2+VAL 2+normal-evaluation 4+historical 2, 총 40개 중 실제 평가 대상은 정상 16+historical 8개다. 반복이 보이지 않는 영상은 cycle 경계 GT를 억지로 만들지 않는다.

FIT에서 단계 이름·좌표 원점을 정하고 평가에는 고정한다. Clock, 관측 기반 추정, 누적 PhysicalTracker를 비교한다. 단계 일치도, 전환 지연/누락, anchor circular error, 중간 시작 성능을 보고한다. 연속 θ를 단계 간 선형 보간해 실제 위치 정답이라고 부르지 않는다. Confidence는 error–coverage 관계로 먼저 검증하며 낮은 confidence 때문에 이상을 숨기는 gate를 즉시 넣지 않는다.

## 5. 이후 연구 우선순위와 주장 분기

| 순서 | 실험 | 구체적인 비교와 역할 |
| --- | --- | --- |
| 1 | E15B0, E15B/C | 작은 범위로 경보 비용·보정 효과를 확인; 낮은 분위수 해상도도 결과로 기록 |
| 병행 | R01 원본 점검, E7B | 정상 라벨/분포와 잠재 좌표의 실제 의미 확인 |
| 2 | 외부 baseline 재현 + E12B | C가 중심이므로 외부 SubspaceAD 및 전역/phase별 PCA의 공정한 비교를 앞당김 |
| 3 | 독립 촬영/보정/평가 | 현재 개발 데이터에서 고른 방법을 고정하고 새 원본·세션에서 확인 |
| 조건부 | E13B/E14B | P를 동등한 핵심 기여로 주장할 때 정지·강한 시간 모델·편집 경계 검증 |
| 최종 | end-to-end streaming | 입력 디코딩·특징·추적·점수·경보까지 batch 1 지연, p50/p95, warmup, peak memory |

E12B는 전체 FIT에서 총 rank 32/64/128의 공유 PCA와 4-bin PCA를 비교하고 실제 유지 rank·평균/기저/보정까지 총 메모리와 시간을 공개한다. 동등 total rank만으로 동등 capacity라고 단정하지 않는다. 실행 전에 matched-memory 설정도 정상 자료만으로 고정한다. 기존 head-only few-shot은 전체 학습 데이터 효율 주장과 구분한다.

외부 baseline은 공식 구현·전처리·추론의 인과성을 점검하고 원 구현 설정과 같은 backbone/입력으로 통제한 설정을 구분한다. 내부 A를 외부 논문의 완전한 재현이라고 부르지 않는다. 온라인 설정을 만족하지 못하면 별도 offline 대조로 표시한다.

독립 촬영은 장면별 새 정상 보정 10개와 평가 정상 10개 원본, 각각 최소 3개 분리 세션을 첫 pilot 목표로 둔다. 이는 표본 확보 목표이며 1% FAR 검증에 충분하다는 뜻이 아니다. 연결된 clip은 하나의 session 그룹으로 취급한다. Pilot의 정상 경보 변동·의존성을 보고 최종 수집량을 계산한다. 평가에 필요한 자연 이상 또는 검증된 실제 공정 이상 사례도 별도 확보하며, 없는 유형의 일반화는 주장하지 않는다. 추가 정상 보정 사용은 commissioning 설정으로 명시하고 기존 무적응 설정도 유지한다.

P의 후속 비교는 P 단독, 다중 lag 차분, global dwell, phase-aware dwell, 다중 horizon AR, causal TCN에 같은 C를 붙이기 전후로 한다. E14B의 낮은 시작 jump 역행과 변화량 대응 대조를 함께 사용한다. 유형은 freeze/reverse/skip/swap으로 분리하며 편집마다 다른 원본인 것처럼 통계 처리하지 않는다. 성공하지 않으면 P는 보조 분석으로 제한해도 C 중심 논문은 성립한다.

최종 판단은 다음과 같다. **논문의 중심은 정해졌고 초안 작성이 가능하다. 추가 실험은 중심을 새로 찾기 위한 것이 아니라, C의 외부 타당성과 P의 적용 범위 및 경보 비용을 확인하기 위한 것이다.**
