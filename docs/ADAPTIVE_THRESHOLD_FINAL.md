# CycleVAD 적응형 임계값·정지 이상 최종 실험

> 과거 실험 보고서. 정지 분기의 초기 미래 참조와 당시 후보 비교 범위는 [새 검토 문서](review/04_local_alarm.md)를 참고한다. 수치가 충돌하면 해당 run의 JSON을 우선한다.

## 목적

기존 CycleVAD는 장면별로 정상 학습 데이터에서 하나의 고정 임계값을 정한다. R01 테스트 영상에는 학습 정상 영상보다 점수 강도가 전반적으로 높은 영상이 있어, 정상 프레임도 임계값을 넘는 문제가 있었다. 이번 실험은 다음 두 문제를 함께 다룬다.

1. 영상별 점수 강도 차이에 맞춰 경보 임계값을 조정해 정상 오경보를 줄인다.
2. 일반 CycleVAD 점수만으로 약했던 정지(stall/freeze) 이상을 별도 시간 특징으로 보완한다.

## 최종 방법

모델 학습과 임계값 산정에는 정상 영상만 사용한다. 테스트 라벨은 모든 점수와 경보가 만들어진 뒤 평가할 때만 읽는다.

### 1. 영상 강도 기반 적응형 임계값

- 테스트 영상 시작부 24개 sampled frame에서 점수가 낮은 20%만 사용한다.
- 이 값과 정상 reference 영상의 시작부 기준값 차이를 `intensity_offset`으로 계산한다.
- 영상별 임계값은 `기존 임계값 + 0.3 × intensity_offset`으로 정한다.
- 이상이 시작부 일부에 섞여도 영향을 줄이기 위해 전체 평균이 아니라 낮은 점수 구간을 사용한다.
- 이상 점수 자체는 변경하지 않으므로 AUROC와 AP 순위 성능은 기존 CycleVAD와 동일하게 유지된다.

### 2. 정지 이상 분기

- DINOv2 global feature의 lag 1·4 cosine motion을 계산한다.
- phase-conditioned 정상 motion 분포의 lower-tail surprisal로 움직임 부족을 점수화한다.
- 8개 sampled frame 중 3개 이상이 임계값을 넘을 때 정지 경보를 낸다.
- 최종 경보는 `적응형 CycleVAD 경보 OR 정지 경보`이다.

## 평가 조건

- 장면: IPAD R01–R04
- 주 평가: frame AUROC, AP, 정상 FPR, 이상 Recall, event coverage
- 정지 평가: 정상 validation feature 일부를 5%, 10%, 20% 길이로 반복시키고 시작 위치를 20%, 40%, 60%로 바꾼 합성 정지 180건
- 테스트 라벨의 학습·보정·임계값 선택 사용: 없음
- 전체 자동 테스트: 57개 통과

## 최종 결과 — R01–R04 macro average

| 방법 | AUROC | AP | FPR | Recall | Event coverage | 합성 정지 Recall |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 고정 임계값 CycleVAD | 0.7828 | 0.6977 | 18.93% | 43.80% | 66.50% | 16.25% |
| 강도 적응형 임계값 | 0.7828 | 0.6977 | **12.76%** | 38.68% | 66.50% | 16.25% |
| **강도 적응형 + 정지 분기** | **0.7828** | **0.6977** | **14.70%** | **47.54%** | **81.56%** | **93.33%** |

강도 적응형만 사용하면 FPR이 6.18%p(상대 32.6%) 감소했다. 최종 결합 모델은 고정 임계값 대비 FPR을 4.24%p 낮추면서 Recall을 3.74%p, event coverage를 15.06%p 높였다. 합성 정지 탐지는 16.25%에서 93.33%로 증가했다.

## 핵심 문제였던 R01

| 방법 | FPR | Recall | Event coverage | 합성 정지 Recall |
| --- | ---: | ---: | ---: | ---: |
| 고정 임계값 CycleVAD | 64.25% | 100.00% | 100.00% | 51.11% |
| 강도 적응형 임계값 | **41.38%** | 84.05% | 100.00% | 51.11% |
| 강도 적응형 + 정지 분기 | 42.86% | **85.09%** | **100.00%** | **73.33%** |

R01 오경보는 크게 줄었지만 완전히 해결되지는 않았다. R01의 일부 정상·이상 영상이 모두 학습 분포보다 높은 점수 영역에 있어, 점수 강도만으로 둘을 완전히 분리할 수 없기 때문이다.

## 폐기한 과도한 정규화

phase-tail 점수 전체를 영상별로 강하게 이동시키는 `warmup_phase` 실험은 보존된 final JSON에서 R01 FPR을 2.30%까지 낮췄지만 Recall이 0%가 되었다. 이는 정상 오경보뿐 아니라 실제 이상 신호까지 제거한 결과다. 따라서 최종안에서는 점수를 바꾸지 않고 임계값만 30% 보정하는 절충안을 사용했다.

## 결론

최종 권장 모델은 **강도 적응형 임계값 + 정지 분기**다. 단순히 FPR만 최소화한 모델이 아니라 기존 CycleVAD의 AUROC/AP를 보존하면서 전체 Recall, event coverage, 정지 이상 대응을 개선했다. 운영 목적이 오경보 최소화에 더 치우치면 정지 분기를 제외한 `강도 적응형 임계값`을 선택할 수 있다.

원시 결과는 `results/adaptive_final/`의 JSON 파일에 저장한다.
