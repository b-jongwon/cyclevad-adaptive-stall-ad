# 위치별 정상 기준과 진행 이상 탐지의 검증 계획

다음 순서는 **E8B 위치 조건의 기여 분리 → E9S 합성 진행 이상 비교**로 정한다. 실제 anchor 주석을 사용하는 E7은 병행한다. 합성 편집의 종류와 시점은 생성기로 알 수 있으므로 E9S를 E7 완료까지 미루지 않는다. 실제 위치 정확도와 실제 공정 이상 유형별 성능은 E7 및 주석 기반 E9R에서 검증한다.

아래 내용은 **실행 전 고정한 설계 스냅샷**이다. 현재 실행 상태와 수치는 [E8B / E9S 결과](PHASE_PROCESS_RESULTS.md)를 따른다. 설정의 `planned_not_run`은 고정 당시 상태이며 사후에 변경하지 않는다. [설정](../configs/experiments/followup/phase_process_v2.json), [편집 사례 목록](../configs/experiments/followup/e9_cases_v2.json), [실행 전 검사](../configs/experiments/followup/phase_process_v2_preflight.json)를 고정한다. 이 계획은 이전 E9의 E7 의존성, 편집 시작점, 주 운영점의 보정 방식을 개정한다. E0–E8의 설정과 결과는 유지한다.

## 출발점과 검증 질문

E8에서 C-22의 주 readout AP는 C-00보다 seed별 +2.829~+3.225 pp 높았다. 그러나 이 비교는 Confidence 처리의 효과를 보여줄 뿐, θ가 있어야 개선되는지는 보여주지 않는다. C-22는 E8 결과를 본 뒤 다음 실험의 대상으로 정한 모델이며, 이전 사전 후보 C-21을 소급해 바꾸지 않는다. [E8 근거](../results/E8/robustness.json)

이번에 구별할 질문은 두 가지다. 첫째, 정상 기준이 **현재 추정 위치에 맞게 달라져야** 유용한가. 둘째, 공정 진행 모델이 **일반적인 변화량과 특징 예측 오차보다** 시간 순서 교란을 잘 탐지하는가. R02의 좋은 기존 수치도 이 두 질문에 대한 답으로 자동 해석하지 않는다.

## 공통 조건

R01–R04의 정상 111개 영상과 고정한 5개 outer fold를 사용한다. 각 fold의 FIT, validation, reference, threshold, normal evaluation은 분리한다. 정상 영상은 한 번만 평가되며 모든 편집본은 원본과 같은 fold에 속한다. 원본 녹화 그룹의 독립성은 아직 확인되지 않았다.

Seed 42로 모든 사전 비교를 실행하고, 설정을 바꾸지 않은 상태에서 43·44를 반복한다. 실제 실험 비용은 첫 fold에서 측정한다. 로컬 RTX PRO 6000에서 얻은 고정 DINOv2 특징을 재사용하며 통계 모델은 CPU에서 학습한다. 기존 IPAD 테스트는 이미 설계에 영향을 주었으므로 fold 0의 탐색적 진단으로만 사용한다. R02 길이 불일치 영상은 기존 strict-v1 규칙으로 제외한다.

## E8B에서 비교할 위치 조건

모든 arm은 Confidence 학습 가중치와 추론 gate를 제거한다. 위치를 쓰는 모델은 하나의 Fourier 평균 μ와 하나의 공유 잔차 PCA를 사용한다.

| ID | 정상 기준에 공급하는 위치 | 분리하려는 효과 |
|---|---|---|
| M0 | θ 없음, 일정한 평균 | 위치 조건 자체의 필요성 |
| M1 | 첫 관측의 위치에서 FIT 기준 속도로 진행하는 시계 | 관측을 계속 추적하는 것이 단순 시간 경과보다 필요한가 |
| M2 | 프레임별 template likelihood의 원형 평균 | 재귀적인 posterior 누적이 필요한가 |
| M3 | 현재 causal filter의 θ, C-22 | 검증 대상 |
| M4 | M3의 θ에 영상마다 다른 고정 offset을 더함 | 공유된 위치 대응의 효과와 Fourier 용량 증가 구별 |

M1은 테스트 영상 길이로 위치를 정규화하지 않는다. M2도 현재·과거 차분을 포함한 동일한 descriptor를 쓰며, 재귀 필터만 제거한다. M4는 영상 안의 위치 변화와 매끄러움은 보존하면서 영상 사이의 위치 대응을 깨뜨린다. Offset은 영상 ID와 고정 seed 1101–1105의 해시로 생성한다. 다섯 결과를 모두 보고하며 가장 불리한 대조군을 고르지 않는다. **모든 영상에 같은 offset을 주고 다시 학습하는 것은 좌표 원점 변경이므로 음성 대조군이 아니다.**

M0에서 일정한 μ를 뺀 뒤 PCA가 다시 평균을 빼면 `z−E[z]`가 남는다. 따라서 동일 샘플·rank·seed에서는 pooled PCA와 동등해야 한다. 기존 appearance가 pooled 분기를 포함하므로 `max(appearance,M0)`도 appearance와 같아야 한다. 이를 먼저 검사한다. M3의 추론 θ만 0으로 바꾸는 방식은 M0로 사용하지 않는다.

### 학습 조건과 공정한 비교

같은 fold/seed의 tracker, pooled/local 외형 분기, 샘플 추출, PCA rank 상한을 공유한다. E8의 seed 42에서 정상 validation으로 정한 Fourier 차수와 ridge를 M1–M4에 고정한다. M0는 차수가 0인 포함 관계의 기준선이다.

M1, M2, M4 각각에 대해 해당 위치로 **μ와 잔차 PCA를 함께 다시 학습**한다. M0 및 M3은 동등성 검사 후 기존 결과를 재사용할 수 있다. 각 arm/readout의 reference 보정과 정상 q99 임계값도 별도로 계산한다. 다섯 큰 비교군 중 M4가 다섯 offset을 가지므로 실제 조건 수는 9개다.

기존 PCA의 95% 분산 기준 때문에 유효 rank가 arm마다 달라질 수 있다. 이를 보고하고, seed 42의 모든 fold에서 M0/M3을 같은 고정 rank로 다시 비교한다. 공통 rank는 두 arm이 허용하는 최대치와 64 중 최솟값이며, 이 보조 비교에서는 분산 기준에 의한 조기 절단을 사용하지 않는다.

고정한 차수·ridge가 다른 위치 대조군에만 불리한지도 점검한다. Seed 42의 모든 fold에서 M1/M2/M3에 동일한 정상 validation 탐색 예산(차수 2/4/8, ridge 0.01/0.1/1)을 주는 보조 실험을 별도로 수행한다. 선택 기준은 정상 μ 재구성 MSE이며, 기존 테스트로 설정을 선택하지 않는다.

### 평가와 판정

| 구분 | 지표와 목적 |
|---|---|
| 조건부 분기 단독 | 위치 조건의 효과가 외형 max 결합에 가려지는지 확인 |
| 외형과 조건부 분기의 max | 이상 탐지 기여의 주 readout; process는 제외 |
| 정상 outer evaluation | 영상별 μ 재구성 MSE, 잔차 PCA 밖의 MSE, 유효 rank, frame FPR 및 영상 평균 FPR |
| 기존 이상 테스트 | 장면별 AUROC/AP, FPR/Recall, 조건부 분기 활성 비율 |

현재 관측으로 θ를 구한 뒤 계산한 μ 오차는 재구성·표현 압축의 지표다. 미래 예측 정확도나 실제 위치 오차라고 부르지 않는다.

주 비교는 **M3−M0**, 위치 대응에 대한 핵심 검사는 **M3−M4**다. M4는 다섯 고정 offset의 평균 대비 효과와 개별 결과를 모두 보고한다. M3−M1, M3−M2는 추가로 필요한 추적 복잡도를 판단한다.

연구 진행 기준은 주 readout의 historical macro AP +1 pp 이상, 각 장면 정상 FPR 증가 ≤1 pp, 두 핵심 비교의 paired 불확실성이 일관된 개선을 지지하는 것이다. CI가 0을 포함하면 미확정으로 남긴다. 이는 실용적인 탐색 기준이며 독립 데이터에서의 확증이나 문헌 표준이 아니다.

- M3가 M0와 M4를 이기면 위치에 맞는 정상 기준의 실험적 근거가 생긴다.
- M3와 M4가 비슷하면 위치 대응보다 추가 함수 용량이나 점수 결합으로 설명될 수 있다.
- M1 또는 M2가 M3와 비슷하면 ②의 가능성과 별개로 복잡한 재귀 추적의 필요성은 입증되지 않는다.
- 정상 MSE만 줄고 탐지 성능이 개선되지 않으면 정상 표현 효과와 AD 기여를 구분한다.

## E9S의 편집 생성과 범위

정상 outer evaluation의 원본 순서를 편집한다. T는 정상 FIT 영상의 실제 원본 프레임 수 중앙값이며 실제 cycle 주석으로 확인한 주기는 아니다. 두 stride에서 같은 T를 사용한다. 편집 길이는 T의 5·10·20%, 시작점은 T의 20·30·40%로 고정한다. 정수화는 round-half-up, 편집 길이는 최소 2프레임이다.

| 편집 | 생성 규칙 |
|---|---|
| 정지 | 시작점 직전 관측을 L프레임 반복 삽입 |
| 역행 | 길이 L 블록의 순서 반전 |
| 생략 | 길이 L 블록 삭제 |
| 순서 변경 | 인접한 L 길이 블록 두 개 교환 |

최소 32프레임의 과거와 편집 이후 0.4T의 원본·편집 평가 구간을 모두 확보한다. 확보할 수 없는 사례는 모든 arm에서 공통으로 제외한다. 편집 강도를 줄이거나 끝 프레임을 padding해서 살리지 않는다.

기존 25·50·75% 시작점은 짧은 영상에서 0.4T 구간을 확보하기 어려웠다. 새 시작점은 **길이 정보만 확인하고 성능 계산 전에** 변경했다. 이에 따라 주 평가의 시작점 범위는 FIT 기준 길이의 앞쪽과 중간에 한정된다.

| 편집 | 후보 | 길이 검사 통과 | 제외 |
|---|---:|---:|---:|
| 정지 | 999 | 993 | 6 |
| 역행 | 999 | 993 | 6 |
| 생략 | 999 | 931 | 68 |
| 순서 변경 | 999 | 993 | 6 |
| 합계 | 3,996 | 3,910 | 86 |

표는 **편집 가능 여부 검사이며 탐지 결과가 아니다**. 정확한 source/fold/시작점/길이/제외 사유는 고정 목록에 있다. seed와 stride를 늘려도 독립 원본 수는 111개다.

### 특징과 온라인 입력

Stride 1의 dense 특징에서 전체 프레임 순서를 먼저 편집한 뒤, 출력 타임라인의 stride 2로 관측한다. 홀수 길이 편집을 이미 성긴 특징에서 처리하면 잘못된 위치를 참조할 수 있기 때문이다. 정상 FIT/validation/reference/threshold도 같은 dense cache에서 stride 2로 추출해 통계 모델을 다시 학습한다.

모델에는 출력 프레임 번호와 편집된 현재·과거 특징만 제공한다. 원본 index map은 평가기에만 제공한다. 차분과 posterior는 편집된 순서에서 다시 계산하고 영상 시작부터 상태를 누적한다. 편집 시작점에서 상태를 초기화하지 않는다.

## E9S의 대조군

A는 동일한 pooled/local appearance 점수이며 모든 합성은 max로 고정한다. 주 비교에는 조건부 외형을 넣지 않아 ②의 효과가 ③의 비교에 섞이지 않게 한다.

| ID | 결합 점수 | 질문 |
|---|---|---|
| P0 | A | 외형만으로 설명되는가 |
| P1 | A와 alignment | 정상 template에서 멀어지는 것만 탐지하는가 |
| P2 | A와 innovation | 전이 예측의 불일치가 필요한가 |
| P3 | A와 progress | 진행량 불일치가 필요한가 |
| P4 | A와 세 process 점수 | 중심 비교 대상 |
| P5 | A와 AR(1) 특징 예측 오차 | 일반적인 학습형 시간 모델보다 좋은가 |
| P6 | A와 2프레임 차분 | 단순 움직임 변화보다 좋은가 |
| P7 | A와 2·8·32프레임 차분 | 같은 시간 범위를 보는 차분 모델보다 좋은가 |
| P8 | A와 innovation 및 progress | alignment 없이도 진행 신호가 기여하는가 |
| P9 | P4에서 재귀 posterior 누적 제거 | 누적 위치 추적이 정말 필요한가 |

P5–P7은 tracker와 같은 정상 FIT PCA 좌표를 사용하지만 θ를 입력받지 않는다. AR(1)은 절편을 포함한 ridge 예측기이며 정규화된 ridge 후보 0.01/0.1/1 중 정상 validation MSE로 선택한다. 시간 간격은 원본 2프레임이다.

**차분 대조군은 큰 변화와 작은 변화의 양쪽 꼬리를 모두 탐지한다.** 큰 차분만 점수화하면 정지에 불리한 대조군을 만드는 셈이다. 각 lag의 정상 reference 분포에서 양측 tail 점수를 구하고, P7은 그 최댓값을 사용한다. 과거가 부족한 lag는 비정상적인 0 움직임으로 취급하지 않고 중립 점수로 둔다. 정확한 CDF·tie 처리식은 설정에 고정한다.

P1의 template descriptor에는 과거 차분도 포함된다. 따라서 P1을 순수 정적 외형 모델이라고 부르지 않으며, 재귀적인 위치 추적 없이 설명되는 효과를 점검하는 대조군으로 사용한다.

P9의 progress는 M2 위치를 사용한다. Innovation prior는 직전 likelihood에 동일한 전이 kernel을 적용해서 얻으며, 이전 posterior를 반복 누적하지 않는다. Alignment와 입력 descriptor는 P4와 같다. 이 비교가 동률이면 재귀적 Bayesian 누적의 추가 기여를 주장하지 않는다.

## E9S의 평가와 오경보 통제

주 순위 지표는 편집 시작부터 0.4T 동안의 최대 점수로 구한 원본 대 편집본 AUROC다. 탐지 이벤트는 시작 후 0.2T 내 첫 경보로 정의한다. 정지·생략으로 전체 길이가 달라져도 평가 구간은 같다.

이벤트를 비교하면서 frame q99만 맞추면 방법마다 정상 구간에서 한 번이라도 경보할 확률이 다를 수 있다. 따라서 주 운영점은 각 arm의 **정상 threshold 영상에서 길이 0.2T window 최대 점수의 q99**로 정한다. 정상 evaluation에서 편집과 동일한 시작점·길이의 원본 window 경보율 및 영상 전체의 고정 간격 window 경보율을 모두 측정한다. q99가 새 정상 영상의 1% 경보율을 보장한다고 해석하지 않는다.

보정 window는 원본 32프레임부터 약 0.1T 간격으로 생성한다. 영상마다 전체 가중치를 같게 하고, 가중 누적 확률이 0.99에 처음 도달하는 관측값을 임계값으로 사용한다. 서로 겹치는 window를 독립 영상으로 세지 않는다. 보정 가능한 threshold 영상이 2개 미만이면 해당 운영점은 미측정으로 남긴다. 기존 frame q99 운영점은 별도 보조 표로 유지한다. 정상 threshold의 q90/q95/q97.5/q99/q99.5를 미리 정한 보조 곡선으로도 비교해 탐지율과 오경보의 교환 관계를 보여준다. 평가 결과를 보고 주 임계값을 선택하지 않는다.

주 비교는 **P4 대 P0/P5/P7**이다. 유형·강도별 event detection, 정상 window 경보율, frame FPR을 함께 보고한다. 지연은 탐지된 사례에 대해서만 계산하고 미탐지 비율을 함께 명시한다. AP에는 평가 positive 비율을 표시한다.

성공 선별 기준은 세 기준선 각각보다 이벤트 탐지율 +5 pp 이상, 장면별 정상 window 경보율 ≤5% 및 각 주 기준선 대비 증가 ≤1 pp, 3/4 이상 장면의 개선 방향 일치, seed 42/43/44의 주 효과 방향 일치다. 5%는 정상 q99의 목표인 1%보다 느슨한 연구 선별 상한이다. 넓은 CI를 성공으로 바꾸지 않는다.

R02만 좋아지거나 P4가 P7을 이기지 못하면 일반적인 cycle 방법의 우월성으로 확대하지 않는다. P1만으로 개선이 설명되고 P8이 약하면 진행 자체보다 template 이탈 검출의 근거로 해석한다. P4가 P9보다 좋다는 근거가 없으면 재귀 추적을 별도 기여로 강조하지 않는다.

## 편집 흔적과 속도 변화 점검

항등 편집은 입력과 점수를 재현해야 한다. 역행·순서 변경은 프레임 집합을 보존하지만 경계의 급격한 차분은 남으므로, 최초 32프레임의 변화와 편집 내부에서 지속되는 경보를 나누어 본다. 충분한 내부 길이가 있는 정지·역행·순서 변경에만 이 분석을 적용하고 대상 수를 보고한다. 생략은 순간적인 전이 사건이므로 존재하지 않는 내부 구간을 만들지 않는다.

0.8·1.0·1.2배 속도 조건도 고정해 비교한다. 실제 공정의 허용 속도가 확인되지 않았으므로 속도 stress 경보율로 보고한다. 합성 편집에서 잘 탐지하더라도 실제 장비의 정지·역행·생략 성능으로 대신하지 않는다.

Stride 1 보조 실험은 seed 42에서 수행한다. Descriptor 4프레임, progress 및 차분 2·8·32프레임, AR(1) 2프레임을 맞춘다. 전이 kernel의 분산과 재시작 확률도 경과한 원본 시간에 맞춰 환산한다. 관측 수와 학습 통계는 달라지므로 완전히 동일한 모델의 단순 샘플링 비교라고 부르지 않는다.

## 집계와 불확실성

원본별 편집 수가 다르면 사례 수가 많은 원본이 결과를 지배하지 않게 원본별 가중치를 맞춘다. AUROC는 장면·fold·유형·강도 안에서 계산하고, fold는 유효 원본 수로 가중한 뒤 강도·유형·장면을 동일 비중으로 평균한다. 서로 다른 fold의 원시 점수를 합쳐 하나의 AUROC로 만들지 않는다. 정상 FPR은 장면별 frame-weighted 값과 영상 평균을 함께 보고한다.

장면별로 원본 파일을 paired bootstrap 2,000회 재표집한다. 모든 편집본·원본 window·offset·seed 결과는 원본에 묶는다. CI는 학습된 모델을 고정한 탐색적 95% percentile 구간이며, 다중 비교 전체의 유의성이나 원본 녹화 독립성을 주장하지 않는다.

## 실행 순서와 논문 기여의 판단

1. E8B fold 0 seed 42에서 M0 동등성, 전체 위치 조건, 두 readout을 검증한다. 성능을 보고 비교군을 줄이지 않고 5-fold와 seed 43·44로 확장한다.
2. E9S 항등 편집·미래 입력 불변성·원본 시간 lag 검사를 통과한 뒤 fold 0 seed 42를 실행한다. 모든 유형과 강도를 포함한다.
3. E9S를 5-fold와 세 seed로 확장하고 stride 1을 보조 검증한다. E8B의 승자에 따라 P0–P9를 바꾸지 않는다.
4. 독립 주석이 준비되면 E7과 실제 유형별 E9R을 수행한다. 외형상 정상적인 진행 이상인지 실제 영상에서 확인한다.
5. 최종 방법을 고정하고 신규 녹화 E10에서 확인한다.

| 관찰 | 허용되는 기여 해석 |
|---|---|
| E8B만 일관된 개선 | 위치별 정상 기준을 중심으로 구성 |
| E9S만 일관된 개선 | 진행 모델을 중심으로 구성하되 실제 이상 검증 추가 |
| 두 실험 모두 개선 | 위치 조건 외형과 진행 이상을 보완적인 두 요소로 구성 |
| 차분/AR(1)과 차이가 불명확 | 일반적인 시간 정보 결합으로 주장을 좁힘 |
