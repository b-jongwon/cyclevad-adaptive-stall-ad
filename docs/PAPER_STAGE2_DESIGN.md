# CycleVAD 논문 기여 검증을 위한 후속 실험 설계

2026년 10월 9일 KST. 기준 커밋은 `33b0adaf211e427e333fd358f8630726c5b14ee1`이다. 첨부된 최신 결과 분석과 [완료 결과](PAPER_STAGE1_RESULTS.md)를 대조해 구성했다. **아래는 신규 실험을 시작하기 전의 설계 스냅샷이다.** 현재 E11B·E15A 실행 상태는 [최소 구성과 오경보 진단 결과](PAPER_DIAGNOSTICS_RESULTS.md)를 따른다. [설계 명세](../configs/experiments/followup/paper_stage2_design_v1.json)는 구현 전 결정 사항을 기록한 파일이며 실행 가능한 runner 설정은 아니다.

논문의 중심은 **정상 공정의 진행에 따라 달라지는 평균 외형을 제거한 뒤, 공유 잔차 공간으로 이상을 평가하고 시간적 진행 불일치를 보완 신호로 사용하는 온라인 탐지**로 잡는다. 위치 추적 정확도, 공유 모델의 선택 근거, 진행 신호의 추가 효과는 각각 별도의 증거로 판단한다. 세 요소 모두를 처음 제안한 알고리즘으로 주장하지 않는다.

## 공통 데이터 사용과 평가 규칙

R01–R04의 정상 5-fold, FIT/validation/reference/threshold/evaluation 역할과 strict-v1 라벨 정책을 유지한다. 주 seed 42, 설정 고정 후 43·44를 반복한다. 원본·모든 편집본은 같은 fold에 둔다. 녹화 세션 ID를 확인하면 세션 단위로 새 버전의 분할을 만들고 파일 분할 결과와 구분한다.

모델은 정상 FIT로 학습한다. 예측 모델의 설정 선택과 early stopping은 정상 validation 손실을 사용한다. Reference는 점수 분포 추정, threshold는 최종 운영 임계값 계산에만 사용한다. 보정·결합 비교군은 사전 지정하고 모두 보고하며, 평가 이상을 본 뒤 최적 비교군만 남기지 않는다. 합성 이상으로 가중치나 구조를 고르는 추가 연구를 한다면 `synthetic-tuned`로 분리하고 정상 데이터만으로 설정한 주 방법과 구분한다.

이미 확인한 historical test와 E9S 원본은 새로운 분할·새 seed·새 편집을 만들더라도 개발 자료다. 기존 OOF 결과를 반복 확인하는 후속 비교 역시 탐색적이다. 최종 확인 실험은 방법·임계값 규칙을 고정한 후 접근할 독립 자료에서 수행한다.

| 평가 축 | 주지표 | 함께 공개할 값 |
| --- | --- | --- |
| 순위 성능 | 장면 macro frame AP, AUROC | 장면별 값, 최악 장면, C 및 C+P 대비 차이 |
| 운영 성능 | 정상 보정으로 고정한 임계값의 event recall | 정상 D-window 경보율, frame FPR, 탐지 지연과 미탐지 비율 |
| 결합 효과 | C+P−C, Full−C+P, Full−A+C | 분기별 고유 탐지, 결합 후 추가·손실 이벤트 |
| 불확실성 | 동일 원본을 묶은 paired bootstrap 2,000회 | seed별 점추정, 주 비교와 보조 비교의 구분 |

D=round(0.2T), W=round(0.4T)는 기존 비교를 위해 유지하되 **T는 약한 recording 시간 척도**라고 표시한다. T를 개선하는 실험에서도 평가 창 D/W는 기존 규칙으로 고정해 모델과 평가 문제가 동시에 바뀌지 않게 한다. 실제 cycle 기준 길이는 독립 주석 후 별도 분석한다.

주 운영점은 정상 목표 window FAR 1%, 보조점은 0.5·2·5%다. 이는 보정 목표이지 평가 FAR 보장이 아니다. 정상 평가셋을 이용해 사후에 임계값을 맞춘 “동일 FAR” 결과를 배포 가능한 성능으로 제시하지 않는다. 전체 곡선은 진단으로 공개하되 실제 운영점은 별도 정상 threshold에서 결정한다. 3–4개 threshold 영상으로 낮은 FAR의 정밀한 일반화 보장을 주장하지 않는다. 녹화 단위 conformal 점수를 쓸 경우 순위 해상도는 1/(n+1), 즉 20–25%에 불과하며, 겹치는 창을 독립 녹화 수로 세지 않는다.

정상 window FAR, 정상 frame FPR, 시간당 경보 횟수는 서로 다른 지표다. 시간당 경보는 FPS/타임스탬프를 확인한 뒤에만 계산한다. 새 분기 결합이 전체 점수의 순위를 바꿀 수 있지만, 최종 점수에 엄격히 단조인 함수만 적용하거나 임계값만 바꾸는 것은 AP/AUROC 개선 방법이 아니다. 이때 동률 처리 차이는 별도로 검사한다.

## 먼저 수행할 최소 구성 비교 E11B

추가 encoder 학습 없이 저장된 E11의 A/C/P 점수를 사용한다. C+P는 새 비교이므로 `E11B`로 기록하고 기존 E11을 덮어쓰지 않는다.

| 비교군 | 정의 | 핵심 질문 |
| --- | --- | --- |
| A, C, P | 각 분기 단독 | 각 신호의 역할은 무엇인가 |
| A+C, A+P | 기존 두 분기 max | 기존 결과 재현 |
| C+P | max(C,P) | 공통 외형 A 없이도 충분한가 |
| A+C+P | 기존 Full | A가 추가로 필요한가 |

Reference/threshold 저장 점수에서 C+P의 정상 임계값을 새로 구한다. 합성 사례의 max(C,P)는 기존 분기별 창 최대값의 max와 같으므로 창 탐지율·순위 지표는 재사용할 수 있다. **새 임계값에서의 지연과 경보 지속시간은 기존 요약 값에서 추정하지 않고 해당 편집 시계열을 재실행한다.** Historical은 저장된 전체 프레임 점수로 정확히 계산한다.

주 비교는 C+P−C와 Full−C+P다. Full−C도 보조 비교한다. AP뿐 아니라 동일 보정 정책에서 실제 추가/손실 이벤트와 오경보를 확인한다. 최종 논문에서 A를 유지할 근거가 약하면 C+P를 최소 방법으로 검증한다. 기존 테스트에서 가장 높은 AP를 얻은 구조를 곧바로 확정 모델로 선택하지 않는다.

산출물은 7개 구성의 장면별 표, branch winner 빈도와 false-positive 기여, paired CI, 이벤트 추가·손실 도표다. 각 장면을 하나씩 제외한 macro, 특히 R02 제외 macro를 민감도 분석으로 함께 보고해 특정 장면의 효과가 전체 평균을 지배하는지 확인한다. 이 분석은 새로운 장면 일반화 실험이 아니다. 기본 범위는 60개 scene×fold×seed, 기존 합성 11,730개 사례다.

## 오경보와 결합을 분리하는 E15

### 진단 E15A

모델을 바꾸기 전에 reference, threshold, 정상 OOF, historical 정상 구간을 비교한다. A의 pooled outside/inside/local, C의 outside/inside, P의 alignment/innovation/progress를 모두 분해한다. 저장하지 않은 원 component는 고정 checkpoint에서 다시 산출한다.

영상별 ECDF·q90/q95/q99·threshold 초과율, 각 분기가 max를 차지하는 비율, phase와 초기 구간별 경보를 그린다. Historical 정상 구간은 첫 이상 이전과 이상 이후로도 나눠 추적 상태 잔류를 진단한다. 이 구분은 평가·진단 전용이다. 조명·배경·공정 상태 원인은 영상 점검 전 가설로 남긴다.

### 보정 비교 E15B

추적기, μ, PCA와 원 점수를 고정하고 세 정책을 비교한다.

| ID | 정책 | 바꾸는 것 |
| --- | --- | --- |
| G0 | 기존 reference tail + 영상 동일 가중 D-window-q99 | 재현 기준선 |
| G1 | reference component CDF도 영상 동일 가중으로 구성 | reference의 영상 길이 편향만 분리 |
| G2 | G1에 phase 4-bin CDF를 전역 CDF로 shrinkage | 정상 phase별 점수 분포 차이 |

G2는 각 bin의 서로 다른 reference 영상 수가 3 이상, stride 표본이 128 이상일 때만 사용한다. bin CDF와 전역 CDF를 0.5:0.5로 혼합하고 그 외에는 전역 CDF로 되돌아간다. 이 숫자는 사전 지정한 공학적 선택이며 확률 보장이나 독립 표본 수의 근거가 아니다. Bin은 현재 causal θ로 정하고 uncertainty 때문에 프레임을 평가에서 삭제하지 않는다. 별도 confidence gate는 도입하지 않는다. 잘못된 θ에 조건을 맞추면서 이상 점수가 낮아지는지도 보고한다.

### 결합 비교 E15C

각 G 정책에서 두 규칙을 비교해 총 3×2 조건만 둔다.

- F0: 기존 max 결합 후, 결합 점수의 threshold 정상 창으로 임계값을 보정한다.
- F1: 사용 분기 수 m에 대해 각 분기의 정상 D-window 경보 예산을 α/m로 나눠 임계값을 정하고 OR로 경보한다. 연속 순위 점수는 각 분기의 영상 동일 가중 reference D-window tail을 사용한 최소 tail probability로 정의한다. 최종 경보와 연속 순위 점수를 혼동하지 않는다.

F1의 목적은 분기 경보 손실과 경보 예산을 드러내는 것이다. 유한 표본·분포 이동이 있는 현재 데이터에서 Bonferroni형 예산이 실제 FAR을 보장한다고 주장하지 않는다. C 단독 α=1%의 탐지 집합을 α/m로 보정한 결합이 보존한다는 주장도 하지 않는다. 임의의 학습 가중치나 장면별 P on/off를 이 실험에 추가하지 않는다.

최소 비교 대상은 C, C+P, A+C+P이고 A/A+C/A+P/P도 최종 같은 정책으로 보고한다. G2는 추가 복잡성이므로 G1 대비 운영상의 이득이 불명확하면 본 방법에 포함하지 않는다. 목표를 만족하는 운영점이 없으면 “미달성”으로 표시한다. 테스트 이상 Recall을 유지하도록 임계값을 사후 조정하지 않는다.

### 판정 기준

채택 후보의 공학적 screening 목표는 정상 OOF macro window FAR ≤2%, 각 장면 ≤5%이면서, 합성 macro event recall이 동일 비교 구성의 기존 운영점보다 3 pp 넘게 낮아지지 않는 것이다. 이는 탐색적 판단 기준이며 목표 1%의 달성 증명이나 정상-only 모델 선택 손실이 아니다. 기존 합성 결과에 따라 후보를 채택하면 그 사실을 기록하고 독립 확인 실험에서만 최종 개선을 주장한다. 모든 사전 후보와 실패를 공개한다.

운영 지표만 좋아지면 “보정 개선”, AP도 변하면 그 원인이 branch/phase 변환에 의한 순위 변화인지 따로 보고한다. R01의 높은 정상 점수가 분포 이동이라면 단순 q 조정으로 해결된 것처럼 해석하지 않는다.

## 실제 진행 의미를 검증하는 E7B

[기존 40개 대상](../configs/experiments/followup/annotation_queue.json)을 유지한다. 장면별 FIT 2, validation 2, 정상 evaluation 4, historical 2개다. **40개 전체가 독립 평가 표본은 아니다.** 정상 평가 16개와 historical 8개는 구분하여 보고한다.

공식 IPAD 배포의 주기 정보가 실제 사건/경계 주석인지 먼저 확인한다. 제공 정보가 주기 클래스나 길이뿐이면 이를 프레임별 위치 GT로 바꾸지 않는다. 원본 녹화 그룹·FPS도 함께 확인한다. 현재 로컬 실험에는 검증된 cycle 경계가 적용되어 있지 않다.

평가 영상 24개는 모델 출력을 보지 않은 두 사람이 독립적으로 단계 전환, 완전 cycle, 정상 대기, 이상 유형을 기록하고 합의 전 불일치를 보존한다. FIT에서 정의한 사건 이름과 template 좌표 원점만 평가에 적용한다. 반복을 관찰할 수 없는 영상은 억지로 1 cycle로 만들지 않고 적용 불가로 표시한다. 현재 주석은 미작성 상태다.

비교는 T0 첫 관측으로 초기화한 FIT 속도 clock, T1 현재·과거 descriptor의 관측 likelihood만 사용하는 추정, T2 **E11 PhysicalTracker**로 한다. T1에도 과거 차분이 있으므로 정적 모델이라고 부르지 않는다. 기존 tracker 예측은 legacy 보조 결과로 남긴다. Posterior entropy/resultant를 추가 저장하더라도 원래 T2의 θ가 수치 오차 범위에서 같아야 한다.

주지표는 사건별 단계 구간 정확도와 전환 지연/누락, 보조지표는 FIT에서 정한 anchor 좌표의 circular MAE다. Anchor 사이를 선형 보간하거나 k/K로 등분한 값을 진짜 연속 θ 정답으로 쓰지 않는다. Confidence는 risk–coverage와 error correlation으로 평가하며, 확률 정답과 보정이 없으면 ECE를 계산하지 않는다.

주석된 정상 속도 변화·정상 대기에서 T0/T1/T2를 비교하고, 초기 위치와 중간 시작에 대한 cold start도 따로 보고한다. 추적 초기화는 영상 전체 길이·정답 경계·미래 영상에 접근하지 않는다. Phase별 정상 μ 재구성 오차 감소를 실제 phase 정확도와 혼동하지 않는다.

정상 holdout에서 T2가 T0/T1보다 일관되게 낫고 주석 합의도가 충분하면 “공정 진행 위치 추적”을 강화한다. 그렇지 않으면 “유용한 인과적 잠재 진행 좌표”로 표현을 좁힌다. Confidence가 낮은 구간에서 이상을 숨기는 gate를 복구하는 것은 별도 효과가 확인될 때만 고려한다.

## 정지 탐지와 강한 시간 대조군 E13B

우선 진단할 가설은 **forward prior가 반복된 같은 외형에서도 posterior 위치를 전진시켜 정지를 감출 수 있다**는 것이다. 사실로 확정하기 전 freeze 구간의 관측 θ, prior θ, posterior θ, innovation, 진행량을 같이 그린다. 기존 P는 이미 prior-observation innovation을 포함하므로 같은 항을 새 기여로 추가하지 않는다.

| ID | 시간 신호 | 분리할 효과 |
| --- | --- | --- |
| Q0 | 기존 P 단독 | 진행 분기 기준 |
| Q1 | lag 2·8·32 다중 시간 차분, 양측 tail | 단순 저동작/급변 탐지 |
| Q2 | global 저동작 지속시간 | phase 정보 없는 dwell baseline |
| Q3 | phase별 정상 저동작 지속시간 | 위치에 따라 허용 대기가 다른가 |
| Q4 | max(Q0,Q3) | 정지 보완 뒤 역행·생략 성능 유지 여부 |
| Q5 | 다중 시점 AR 및 causal TCN 예측 오차 | 강한 일반 시간 모델 대비 효과 |

Q1–Q5는 P 비교에서 A를 포함하지 않는다. 기존 P7은 A를 포함하므로 숫자를 그대로 Q1 단독 결과로 재명명하지 않는다. 시간 분기 비교 후 동일 C와 결합해 평가한다.

Q2/Q3의 저동작 기준은 정상 FIT의 lag-2 latent 이동량 10% 분위수 이하로 고정한다. 반복된 저동작 구간의 누적 길이를 정상 reference run-length survival로 점수화한다. Q3는 run 진입 시의 관측 θ로 4-bin context를 고정해 prior가 구간 중 θ를 밀어도 context가 달라지지 않게 한다. bin별 3개 이상 원본, 완결 run 20개 이상일 때 전역 survival과 0.5씩 혼합하고 부족하면 Q2로 되돌아간다. 영상 끝에서 잘린 run은 완료된 dwell로 세지 않고 우측 검열한다. 전역 reference에도 완결 run이 없으면 survival tail을 추정했다고 하지 않고 unavailable로 기록한다. 외형이 반복되는 대기와 공정 정지의 구분 한계도 기록한다.

AR/TCN은 같은 frozen latent 입력으로 2·8·32 원본 프레임 후 특징을 예측한다. t의 점수는 t−h에 발행해 둔 예측과 현재 관측의 차이로 계산한다. TCN은 과거 128 원본 프레임 이내, causal convolution, channels 32/64 × learning rate 1e−4/3e−4/1e−3의 6개 설정, 최대 50 epoch, 정상 validation loss 기준 patience 5로 제한한다. 미래 정규화와 테스트 전체 영상 min-max는 금지한다. 초기 미발행 예측의 coverage를 공개한다.

주 평가는 freeze event recall과 정상 대기 FAR, 보조 평가는 reverse/skip/swap 및 smooth speed 변화의 경보율이다. Freeze는 0.05·0.1·0.2·0.4T로 확장하고, 기존 0.05·0.1·0.2T 수치와 확장 결과를 구분한다. 시간 워핑된 정상 순서 영상은 **순서 보존 스트레스**라고 부르며 모든 속도 변화가 실제 정상이라고 가정하지 않는다. 정상 대기 여부는 E7 주석 또는 작업 규칙으로 확인한다.

채택 screening은 Q4가 Q0보다 freeze event recall +10 pp 이상, 다른 세 편집 유형의 평균 하락 ≤3 pp, E15의 정상 FAR 목표 충족이다. Q2보다 Q3가 낫지 않으면 “phase-aware dwell의 기여”를 주장하지 않는다. Q5보다 낫지 않으면 복잡한 진행 모델의 필요성을 다시 평가한다. 이 기준은 탐색적인 공학 목표이며 독립 검증을 대체하지 않는다.

T 민감도는 주석과 병행한다. 기존 recording 길이 T와 FIT-only 자기유사도/자기상관으로 구한 T를 비교한다. 후자는 정상 validation의 예측 손실·주기 일관성으로 선택하고, 주기가 식별되지 않으면 unavailable로 둔다. FIT 실제 cycle 주석으로 정한 T는 진단용 상한 비교이며, 이를 주 모델에 사용하면 추가 정상 주석을 사용하는 설정이라고 명시한다. 평가 영상 주기는 입력하지 않는다.

## 편집 경계와 상태 잔류를 구별하는 E14B

E14A를 더 긴 내부 창으로 반복하는 것만으로는 순서 효과를 분리할 수 없다. 다음 두 비교를 추가한다.

첫째, reverse의 시작을 바꾼다. 기존 방식은 멀리 떨어진 source 프레임으로 뛰어간 뒤 역행한다. 새 방식은 onset 직전 프레임에서 시작해 바로 앞 프레임들을 역순으로 재생한다. 대조군은 같은 직전 프레임을 한 번 반복한 뒤 정상 전진한다. 두 입력은 첫 편집 프레임까지 동일하며, 큰 시작 jump를 줄인 상태에서 이후 진행 방향이 달라진다. 길이·onset 후보는 모델 점수와 무관하게 사전 고정한다. 첫 32프레임 이후 내부 평가를 별도로 하며, 끝에서 원본으로 복귀할 때 생기는 jump는 내부 평가에 넣지 않는다. 창이 부족하면 eligible coverage와 제외 이유를 보고한다.

둘째, skip/swap에는 정상 전환 및 순서 보존 속도 변화 중 latent 차분 크기가 비슷한 대조 창을 찾는다. FIT에서 정한 lag 2·8·32 차분 크기 표준화 거리로 짝을 고르고, 모델의 이상 점수로 짝을 선택하지 않는다. 허용거리와 매칭 실패는 사전 기록한다. 이 조작만으로 실제 정상 여부를 보장할 수 없으므로 “변화량 대응 스트레스 대조군”으로 표시하고, 인간이 확인한 정상 전환과 분리한다. 대응 가능한 subset과 전체 결과를 함께 보고한다.

복귀 후에는 정상 입력에서 경보가 32프레임 연속 해제되기까지의 시간을 측정하고, 관찰 창 내 미회복을 우측 검열한다. θ가 대응 원본 궤적으로 돌아오는 시간은 별도의 상태 회복 지표다. 대응 source map은 평가에만 사용한다. 주 결과에서는 tracker를 reset하지 않는다. 참 경계를 아는 reset은 원인 분석 전용이며 온라인 방법의 성능으로 계산하지 않는다.

큰 시작 jump가 없는 reverse에서도 Q0/Q4가 차분·TCN 대비 이점을 보일 때 순서 불일치에 대한 근거가 강해진다. 사라지면 “경계 변화 또는 상태 교란 감지”까지 주장 범위를 좁힌다.

## 공유 공간의 예산 의존성을 검증하는 E12B

①과 ③만 보완하다가 가장 강한 ②의 반론을 남기지 않도록 작은 capacity 비교를 추가한다. μ, FIT 표본, calibration과 θ는 고정한다. 연속 평균 조건에서 다음 두 관점을 모두 공개한다.

- 총 rank 32·64·128: 공유 R 대 4/8-bin R/K. 현재 E12의 예산 비교를 확장한다.
- 위치당 rank 16·32·64: 공유 r 대 4/8-bin 각각 r. 후자는 총 rank·bytes가 더 크므로 용량을 추가한 baseline이다.

분할별 표본 수가 실제 rank를 지원하지 않으면 사전 규칙에 따라 unavailable로 기록한다. 특히 rank sweep에서는 일부 조건만 몰래 rank를 낮춰 서로 다른 x축 값을 같은 예산으로 표시하지 않는다. 공통 지원 subset과 전체 coverage를 함께 제시한다. 별도 PCA마다 centering이 있다는 점도 유지·공개한다.

주 결과는 full-FIT seed 42, 20개 scene/fold의 head AP와 실제 모델/보정 bytes, head 지연의 곡선이다. seed 43/44는 사전 지정한 총 rank 64와 위치당 rank 64의 비교만 반복한다. 고정된 normal validation 선택 규칙 밖에서 테스트 AP로 가장 좋은 rank를 선택하지 않는다. Phase별 모델이 더 큰 예산에서 따라잡으면 “정확도에서 항상 우수” 대신 “제한된 예산·표본에서 유리”로 기여를 한정한다.

## 외부 방법과 실제 온라인 처리 비교

SubspaceAD는 frozen DINOv2 patch 특징과 PCA 잔차를 사용하는 이미지 이상 탐지 방법이므로 [공식 코드](https://github.com/CLendering/SubspaceAD)의 framewise baseline을 추가한다. 현재 A는 pooled/local 결합이라 SubspaceAD 공식 재현과 같지 않다. [공식 설명](https://clendering.github.io/SubspaceAD/)

IPAD는 period memory와 sliding-window inspection을 사용하는 직접 관련 산업 VAD baseline이다. [공식 코드](https://github.com/LJF1113/IPAD)와 원 학습 규칙을 확인한다. 합성 사전학습/LoRA 등 추가 데이터를 사용하는 원 설정은 그 사실을 표시한다. [공식 프로젝트](https://ljf1113.github.io/IPAD_VAD/)

INFP는 주기적·동적 정보를 주파수 특징으로 다루는 추가 관련 방법이다. 구현·재현 가능성 점검 후 비교하고, 공식 구현/설정이 확보되지 않으면 재현 미완료로 남긴다. [IJCAI 2025 논문](https://www.ijcai.org/proceedings/2025/0256.pdf)

동일 특징의 내부 비교와 원 방법 설정의 외부 비교를 별도 표로 작성한다. 모든 재현의 데이터·라벨 마스크·점수 정렬·미래 접근 여부·메모리·학습 예산을 공개한다. 미래 프레임을 쓰는 원 방법은 offline 참고 표에 두고, causal 수정판을 만들면 원 방법과 다른 수정판이라고 표시한다. 논문의 공개 수치를 현재 strict-v1 재현 수치와 같은 표본의 직접 승패로 섞지 않는다.

로컬 RTX PRO 6000에서 실제 프레임 입력의 batch1 streaming runner를 구현한다. 디코딩/전처리→GPU 전송→DINOv2→descriptor→tracker→C/P→보정/경보를 모두 계측한다. Dense 특징 캐시는 메커니즘 비교에만 재사용하며 streaming 측정에서는 사용하지 않는다. GPU 동기화, warmup 100프레임, 측정 1,000프레임 이상, 3회 반복의 p50/p95/p99, peak VRAM/host RAM을 보고한다. 데이터가 짧으면 반복 경계의 reset과 비용을 표시한다.

Stride 1/2를 구분하고 frame arrival 대비 경보 완료 지연과 backlog를 측정한다. 같은 prefix 뒤의 미래 입력을 바꿔도 prefix 출력이 같아야 한다. 실제 입력 FPS가 확인되지 않으면 처리 ms/frame과 설정한 목표 rate에서의 replay만 보고하고 실시간 주장을 보류한다.

## 독립 검증과 논문 주장 확정

기존 R01–R04와 그 합성 편집은 개발 결과로 계속 공개한다. 로컬에는 S01–S12도 있으므로 기존 사용 이력과 세션/asset 중복을 감사한 뒤, 미사용 장면이 확인되면 방법을 고정한 후 전체 미사용 장면 묶음을 평가할 수 있다. 이는 같은 IPAD 안의 합성 장면 확장으로서 새로운 실사 촬영을 대신하지 않는다. 좋은 S 장면만 골라 보고하지 않는다.

신규 실사는 서로 다른 반복 공정 2개 이상에서 세션 단위로 촬영한다. 작업 규칙으로 정상 대기/속도 허용 범위를 먼저 정하고, 정상, 외형만 이상, 진행만 이상, 둘 다 이상을 구분한다. 조명/배경 변화와 정상 대기를 포함하고 모델 점수로 사례를 선정하지 않는다. 인위적으로 만든 실제 공정 이상은 자연 발생 고장과 구분한다.

새 공정의 normal FIT/validation/reference/threshold 세션을 평가 세션과 분리한다. 새로운 공정에서 정상 모델을 fit하는 것은 허용하지만, 고정된 알고리즘을 재학습한 결과로 명시하며 zero-shot이라고 부르지 않는다. 구체적인 운영 pilot 목표는 공정당 독립 test session 10개, session당 정상 30분과 이상 유형별 최소 1개 확인 가능한 episode다. 따라서 정상 노출 목표는 총 10시간, 이상 episode 목표는 유형별 최소 20개다. 같은 세션 내 episode를 독립 녹화로 세지 않는다. 확보량이 부족하면 실제 수와 넓은 구간을 보고하고 일반화 주장을 축소한다.

짧은 실험으로 매우 낮은 시간당 경보율을 검증했다고 주장하지 않는다. 예를 들어 단순 Poisson 가정에서 10시간 동안 경보 0회라도 95% 단측 상한은 약 0.30회/시간이며, 실제 경보의 군집성이 있으면 이 계산도 낙관적일 수 있다. 최종 운영 목표를 정하면 필요한 정상 노출 시간을 별도로 산정한다.

최종 공헌의 주 비교는 C 대 전역 평균 baseline, C+P 대 C, Full 대 C+P다. 진행-only 실제 이상에서 추가 탐지가 있고 외형-only 및 정상 대기의 성능 저하가 제한될 때 “상보적 결합”을 주장한다. 기존 seed42 bootstrap이 양수라는 이유로 독립 검증을 통과했다고 하지 않는다.

새 모델이 나오면 최종 통합 재평가를 별도 `E11_final` 버전으로 기록한다. 모델·분할·특징·편집 manifest·선택 규칙·코드 hash를 고정하고, 완성된 단계마다 raw metrics와 검증 로그, README 표/그림을 GitHub에 함께 올린다. 설계만 한 단계, 주석 대기, 미구현 baseline은 완료로 표시하지 않는다.

현재 자료로 가능한 계산은 E7 주석 때문에 멈추지 않는다. 다만 실제 위치 정확도·실제 정상 대기·실제 진행 유형별 주장은 주석 전까지 확정하지 않는다. 첫 실행 묶음은 **E11B + E15A**로 제한해, 새 모듈을 학습하기 전에 필요한 최종 구성과 실패 원인을 확인한다.
